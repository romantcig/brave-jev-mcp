# 影子期标注规则与黄金样本（2026-09-19）

影子期审核用同一把尺子，阈值才有依据。本文件是"人工怎么判一个来源该不该留"的唯一权威说明。

## 尺子：原创性，不是质量

老大的原则只有一条判据：**这一页有没有原创信息或原创分析**。不看域名、不看是否官方、不看写得好不好。

| 判"留" | 判"丢" |
|---|---|
| 一手来源：查询对象自己发的公告、文档、仓库、论文、帖子 | 转述稿：事实全部转引自别处，且前面幸存的来源已经覆盖 |
| 原创论证：作者自己带理由的比较、实测、批评，**包括"我没跑过但我怀疑"这类有论据的怀疑** | 模板填充：只重复主题词、套话、FAQ 拼装，无具体事实 |
| 独有事实：别的来源没有的数字、引语、端点、细节，哪怕只有一句 | 无关：与 query / intent 不是一个主题 |
| 原创整理：自制的对照表、时间线，标注了出处 | 非文章页：列表页、feed、只剩元数据的媒体页 |
| 原文抓不到时的唯一转述版本 | 自称废弃或针对更旧版本且未展示现行做法 |

三档结局：来源留；来源留但只留高分片段；来源丢。"页里只有一句独有事实"归第二档，不归第三档。

## 标注时的固定问法

按顺序问自己，第一个答"是"的即结论：

1. 与主题无关？→ 丢
2. 不是一篇文章（列表、feed、元数据页）？→ 丢
3. 自称废弃，或针对旧版本且不展示现行做法？→ 丢
4. 有作者自己带理由的评价？→ 留（不管事实是否重复）
5. 是当事方自己发的？→ 留
6. 有前面幸存来源没有的事实？→ 只有一两句就"片段级留"，成段就"留"
7. 以上都不是 → 丢，原因写"转述"或"模板"

## 影子期新增样本的规则

- 每条新样本按同一问法标注，标注人写明命中的是第几问。
- 一个来源被标"边缘"就必须补一句"缺什么才能定"，不允许边缘长期挂着。
- 中文来源单独一张表，同一尺子。
- 标注表随夹具进 `fixtures/`，公开无妨（不含 Jev 数字）。
